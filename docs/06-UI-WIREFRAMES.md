# TJ Plex Media Manager - UI Wireframes

## Design System

### Colors (Dark Theme)
- **Background**: `#0a0a0a` (near black)
- **Surface**: `#141414` (dark gray)
- **Surface Elevated**: `#1a1a1a` (card backgrounds)
- **Border**: `#2a2a2a` (subtle borders)
- **Text Primary**: `#ffffff`
- **Text Secondary**: `#888888`
- **Accent**: `#14b8a6` (teal/cyan)
- **Accent Hover**: `#0d9488`
- **Success**: `#22c55e`
- **Warning**: `#eab308`
- **Error**: `#ef4444`

### Typography
- **Font Family**: Inter, system-ui, sans-serif
- **Headings**: Bold, larger sizes
- **Body**: Regular weight

### Spacing
- Base unit: 4px
- Common spacings: 8px, 12px, 16px, 24px, 32px

### Border Radius
- Small: 4px
- Medium: 8px
- Large: 12px (cards)

## Responsive Breakpoints

| Breakpoint | Width | Layout |
|------------|-------|--------|
| Mobile | < 640px | Single column, bottom nav |
| Tablet | 640px - 1023px | Single column, bottom nav |
| Desktop | ≥ 1024px | Sidebar + main content |

Tailwind classes:
- `sm:` = 640px+
- `md:` = 768px+
- `lg:` = 1024px+
- `xl:` = 1280px+
